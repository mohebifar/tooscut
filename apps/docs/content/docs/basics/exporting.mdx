---
title: Exporting Your Project
description: Export your finished edit as an MP4 file with Tooscut.
---

<kbd>⌘E</kbd> or **File > Export** opens the export dialog. GPU-rendered frames are encoded with WebCodecs (WASM fallback).

![Export dialog](../_images/export-dialog.png)

## Quality presets

| Preset     | Bitrate |
| ---------- | ------- |
| **High**   | 20 Mbps |
| **Medium** | 10 Mbps |
| **Low**    | 5 Mbps  |

Resolution and frame rate come from [project settings](/docs/basics/project-settings).

## Exporting a range

If you've set [in/out points](/docs/basics/markers-and-in-out-points), the dialog shows an **Export in/out range only** checkbox. Leave it unchecked to export the full timeline.

## Export stages

1. **Preparing** — Building the render pipeline.
2. **Rendering** — GPU compositing each frame.
3. **Encoding** — Encoding the audio track.
4. **Finalizing** — Muxing audio and video into MP4.
5. **Complete** — Shows total duration and render time.

The file streams directly to disk via the File System Access API.

## Cancelling

**Cancel** aborts at any time. The partial file may remain on disk.

## Leaving during an export

An export runs in the editor. If you try to open another project, return to the dashboard, reload the page, or close the tab while a render is in progress, Tooscut asks you to confirm first. Choose **Keep exporting** to stay, or **Leave anyway** to stop and discard the render. This prevents an accidental click or reload from throwing away the render and the local file access you granted for the project.
